What this dashboard does

The operator pipeline is an autonomous worker that pulls citizen-submitted road images from Supabase, runs them through the two-stage GeoAI classifier, and writes results back. You control when it runs — the worker only processes images when you click Start.

Status flow per image

  • pending — Image uploaded by citizen, waiting in queue
  • processing — Worker has claimed it and is running inference
  • classified — AI is confident (≥80%) — saved as final result
  • expert_review — AI is uncertain (<80%) — needs human review in the Expert UI
  • done — Expert has reviewed and confirmed
  • failed — Worker exhausted retries (network errors, corrupt image, etc.)
