# Bengaluru ward reference layer

`bbmp-198-wards.geojson` is the historical **198-ward Bangalore boundary dataset (2012)** from DataMeet's Municipal Spatial Data repository. It is a reference overlay, not a representation of the current administrative delimitation.

- Source file: https://github.com/datameet/Municipal_Spatial_Data/blob/master/Bangalore/BBMP_oldWards.geojson
- Source README / dataset licence: https://github.com/datameet/Municipal_Spatial_Data/blob/master/Bangalore/Readme.md
- Downloaded: 29 October 2026
- Licence specified by the Bangalore dataset README: **Creative Commons Attribution-ShareAlike 2.5 India** — https://creativecommons.org/licenses/by-sa/2.5/in/
- Attribution: Bangalore municipal ward boundaries by the DataMeet India community.
- SHA-256: `06263e1a1e72fc58844a635c0b95e490962321e8489b476f2379771ce5128633`
- Features: 198 MultiPolygons, WGS84 longitude/latitude.
- Modifications: none; the original file is shipped byte-for-byte under a descriptive filename.

The map attributes the source and licence when the layer is enabled. Hover statistics use loaded, filtered, visible drive-video segments. A segment is assigned by its centre, and its length is counted once when its final class is distress. Segments crossing a boundary are not split; GNSS uncertainty also affects attribution near ward borders. These are approximate survey summaries, not administrative totals.
